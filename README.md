# ConectaCódigo — Projeto de Matemática

Site educativo sobre Linguagem de Programação, feito com HTML, CSS e JavaScript.

## Como visualizar
Abra o arquivo `index.html` no navegador. Para uma experiência melhor, use uma janela de navegador em tela cheia.

## Como publicar no GitHub Pages
1. Entre em https://github.com e crie um repositório público.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na própria página de configurações.

## Estrutura
- `index.html`: conteúdo e estrutura.
- `style.css`: cores, layout e responsividade.
- `script.js`: menu, calculadora, demonstração de condição e quiz.

O site não precisa de servidor ou banco de dados. A fonte externa é carregada do Google Fonts; o restante funciona como arquivos estáticos.
