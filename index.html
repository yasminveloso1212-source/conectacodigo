01 — FUNDAMENTOS

O que é uma linguagem
de programação?

É um conjunto de regras e comandos que permite escrever instruções para um computador executar.

⌨

Uma forma de dar instruções

Assim como usamos idiomas para nos comunicar, usamos linguagens de programação para indicar ao computador o que fazer. Essas instruções precisam seguir regras chamadas sintaxe.

Problema→Algoritmo→Código→Resultado
◇

Algoritmo

É uma sequência finita e organizada de passos para resolver um problema ou realizar uma tarefa.

{ }

Programa

É um conjunto de instruções escritas em uma linguagem que pode ser interpretada ou compilada para execução.

02 — CONHEÇA AS FERRAMENTAS

Cada linguagem tem
seu propósito.

Existem muitas linguagens. Algumas são mais usadas em sites, outras em aplicativos, sistemas, jogos e pesquisas.

PyVersátil

Python

Tem sintaxe simples e é muito usada em automação, ciência de dados e inteligência artificial.

print("Olá, mundo!")
JSWeb

JavaScript

Adiciona interatividade a páginas e aplicações web, como menus, jogos e formulários.

console.log("Olá!");
♨Aplicações

Java

É utilizada em sistemas corporativos, aplicações e diversos projetos de grande porte.

System.out.println("Oi");
CDesempenho

Linguagem C

Conhecida pelo desempenho e pelo uso em sistemas operacionais e programação de baixo nível.

printf("Olá, mundo!");
✦Visual

Scratch

Usa blocos visuais para ensinar lógica, sequências, eventos e criação de histórias e jogos.

quando clicar → diga "Oi!"
03 — MATEMÁTICA + TECNOLOGIA

Programar também
é pensar matematicamente.

A Matemática ajuda a organizar o raciocínio, identificar padrões e construir soluções. A programação transforma essas ideias em instruções.

  • ✓ Lógica e resolução de problemas
  • ✓ Operações e expressões numéricas
  • ✓ Variáveis, funções e relações
  • ✓ Sequências, padrões e geometria
EXEMPLO DE ALGORITMO● AO VIVO
y = 2x + 3

Uma expressão matemática pode ser representada em código.

// Para x = 4
let x = 4;
let y = 2 * x + 3;
console.log(y);
